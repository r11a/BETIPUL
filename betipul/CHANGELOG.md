# Changelog

## 0.1.4

- תיקון אתחול PostgreSQL תחת פרופיל AppArmor ללא הרשאת `CAP_FOWNER`.
- שינוי הרשאות תיקיית מסד הנתונים מתבצע כעת כבעלים `postgres` ולא כ־root.
- בדיקת תמונה עם `FOWNER` חסום כדי לדמות את סביבת Home Assistant.

## 0.1.3

- תיקון בניית כתובת ה־API כאשר נתיב Home Assistant Ingress אינו מסתיים בלוכסן.
- הודעת תקשורת מפורשת כאשר שער Ingress מחזיר תשובה שאינה JSON.
- בדיקות יחידה לנתיבי API מקומיים ונתיבי Ingress.

## 0.1.2

- הסרת כתובת Web UI עצמאית שהתנגשה עם פתיחת הממשק דרך Home Assistant Ingress.
- בדיקת CI ייעודית להזדהות האוטומטית באמצעות כותרות המשתמש של Home Assistant.
- הבהרת כתובת ה־HTTP המקומית והצורך בהפעלה מחדש לאחר שינוי פרטי התחברות.

## 0.1.1

- תיקון אתחול PostgreSQL בתמונת Home Assistant App.
- שימוש במחולל UUID המובנה ב־PostgreSQL 17 ללא תלות ב־pgcrypto.

## 0.1.0

- ממשק עברי RTL רספונסיבי לניהול קליניקה.
- תיקי טיפול פרטניים, זוגיים, משפחתיים וקבוצתיים.
- אנשים ומשתתפים, יומן, מניעת חפיפות ותיעוד קליני חתום.
- הרשאות לפי תפקיד ו־Audit append-only.
- הצפנת AES-256-GCM לשדות רגישים.
- גיבוי מוצפן ומאומת ל־Home Assistant Share / Synology.
- PostgreSQL מקומי, migrations, Ingress וממשק עצמאי אופציונלי.
- מעקב כספי פנימי ועבודה מול גופים מזמינים.
