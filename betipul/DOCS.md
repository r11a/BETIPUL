# תיעוד התקנה ותפעול

## התקנה

1. ב־Home Assistant פתחו **Settings → Apps → App store**.
2. הוסיפו את `https://github.com/r11a/BETIPUL` כמאגר מותאם.
3. התקינו את **בטיפול**.
4. הגדירו סיסמת מנהל וסיסמת גיבויים ייחודיות לפני ההפעלה הראשונה.
5. הפעילו **Show in sidebar** ופתחו דרך Ingress.

## Synology

חברו את שיתוף ה־Synology ל־Home Assistant כ־Network Storage מסוג Share. בתוך היישום הגדירו נתיב יחסי כגון `BETIPUL/Backups`. מסד PostgreSQL הפעיל נשאר ב־`/data`; רק חבילות `.btpbackup` מוצפנות נכתבות ל־`/share`.

בצעו גיבוי ידני ראשון ולחצו **בדיקת תקינות**. שמרו את סיסמת הגיבוי ואת מפתח השדות בעותק מאובטח נפרד. אובדן מפתח ימנע שחזור.

## גישה עצמאית

פורט 8787 כבוי כברירת מחדל. אם מפעילים אותו ברשת המקומית, הכתובת היא `http://HOST:8787` והגישה דורשת את שם המשתמש והסיסמה מהגדרות היישום. לאחר שינוי פרטי ההתחברות יש להפעיל מחדש את היישום. לחשיפה מחוץ לרשת המקומית יש להציב לפניו HTTPS ו־VPN או reverse proxy מאומת; אין לפנות ישירות לפורט באמצעות `https://`. ה־API חוסם התחברות עצמאית כאשר נשארה סיסמת ברירת המחדל או סיסמה קצרה מ־12 תווים.

## אחריות ותאימות

המערכת מספקת הצפנה, הרשאות, Audit וגיבוי; היא אינה מעניקה אישור משפטי או חשבונאי. יש להשלים סיווג מאגר, מסמך הגדרות מאגר, נהלי אירועים ושחזור, בדיקת הרשאות, ייעוץ פרטיות וייעוץ רו״ח לפני שימוש אמיתי.

רכיב הכספים הוא מעקב פנימי בלבד ואינו מפיק חשבוניות או קבלות רשמיות.
