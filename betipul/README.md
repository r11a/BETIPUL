# בטיפול

מרחב בטוח לטיפול. שקט לניהול.

Home Assistant App לניהול קליניקה פסיכולוגית פרטית: תיקי טיפול פרטניים, זוגיים ומשפחתיים, יומן, תיעוד קליני מוצפן, עבודה מול גופים, מעקב כספי וגיבוי מוצפן ל־Synology.

## לפני ההתקנה

- החליפו את `admin_password` בסיסמה ייחודית בת 12 תווים לפחות.
- החליפו את `backup_passphrase` בסיסמה ארוכה ושמרו אותה מחוץ לשרת.
- אל תחשפו את פורט 8787 ישירות לאינטרנט. העדיפו Ingress או VPN.
- המערכת בשלב experimental ואינה מיועדת עדיין לנתוני אמת ללא בדיקת אבטחה ומשפטית.

ראו [תיעוד מלא](DOCS.md).
