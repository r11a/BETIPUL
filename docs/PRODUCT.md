# מפת מוצר והשוואת שוק

ההשוואה נעשתה מול TherapyNotes, SimplePractice, Jane, טיפולוג ו־Medform. המטרה אינה להעתיק את כולן אלא לבנות זרימה ממוקדת לבריאות הנפש בישראל.

## קיים ב־0.1.0

- תיק טיפול נפרד מאדם, עם תמיכה בפרטני/זוגי/משפחתי/קבוצתי.
- כמה משתתפים, גוף מזמין ומשלם לכל תיק.
- יומן, מניעת חפיפות, קליניקה/אונליין/בית.
- תיעוד חופשי, SOAP, DAP, BIRP, קליטה וסיכום; טיוטה/חתימה/גרסה.
- מעקב חיובים ויתרות ללא התחזות למסמך מס.
- הרשאות, Audit וגיבוי Synology מוצפן.

## Roadmap

1. בדיקות משתמש עם מטפלים, הקשחת הרשאות ושחזור.
2. טפסי Intake, הסכמות, חתימה, פורטל מטופל ותזכורות.
3. חדרים, צוות רב־מטפלים, סופרויז'ן ודוחות לגופים.
4. אינטגרציית חשבוניות/סליקה ישראלית רשומה.
5. מדדי תוצאה, ייבוא/ייצוא מלא ו־API.
